# F1 폰으로 Google 저장 연결

현재 운영 순서는 맨 아래 **#59 실제 운영 순서** 참고. 관리자 화면 비밀번호는 필요 없고 첫 폰 등록으로 유지한다. 기존 ADMIN_KEY는 호환·복구용 선택 사항이다.

Android Chrome 기준. Apps Script 편집기가 좁으면 Chrome 메뉴 **데스크톱 사이트**를 켜고 가로로 돌린다. iPhone Safari도 **데스크탑 웹 사이트 요청** 사용. 편집기가 지원되지 않으면 PC가 필요할 수 있다.

1. Drive 앱에서 **+ → 폴더**로 비공개 전용 폴더 생성. 폴더 **공유 → 링크 복사**에서 `folders/` 뒤 ID만 메모. 공유 범위는 **제한됨** 유지.
2. 폰 브라우저에서 [Code.gs](https://github.com/qqcppc/relay-reading/blob/main/apps-script/Code.gs) 열기 → **Raw** → 코드 전체 선택·복사.
3. 같은 브라우저에서 [script.google.com](https://script.google.com/) → **새 프로젝트** → 기존 `Code.gs` 내용 전체를 복사한 코드로 교체 → 저장.
4. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 추가**. `DRIVE_FOLDER_ID`에 1번 ID, `API_KEY`에 길고 임의적인 그룹 공유키, `ADMIN_KEY`는 기존 도구 호환·복구가 필요할 때만 별도의 긴 키로 추가. 입력·저장. ADMIN_KEY는 본문을 넣는 사용자만 보관. 공유키는 공개 저장소나 단체 공개 글에 올리지 않는다. `STATE_FILE_ID`는 자동 생성: 직접 수정 금지.
5. 오른쪽 위 **배포 → 새 배포 → 유형 선택(⚙) → 웹 앱**. 실행 사용자 **나**, 액세스 **모든 사용자** → **배포**.
6. **액세스 승인**에서 본인 계정과 요청된 Drive 권한 확인·승인. 직접 만든 스크립트인 경우에만 Google의 미확인 앱 안내에서 **고급 → 본인 프로젝트로 이동**. 조직에서 익명 배포를 막으면 관리자 확인 필요.
7. 표시된 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사.
8. 낭독 화면 **③ 길게 누르기 → 설정 → 실험 기능 → F1 ON**. 다시 설정을 열어 **연결 주소**에 7번 주소, **공유키**에 4번 키 입력 → **연결**. 잘못된 주소·키는 연결 실패로 표시.
9. 초기 공유 본문은 비어 있다. **③ 길게 누르기 → 설정 → 관리자 키 확인 → 본문 편집**에서 제목·본문 입력 후 **녹음 삭제 동의 → 저장**. 형식은 [UI.md](../UI.md) 참고. 기존 본문을 다시 저장하면 녹음이 모두 지워진다.
10. 다른 폰도 같은 주소·공유키로 연결해 녹음·조회·재생 시험. **해제**는 이 폰의 연결 정보만 지운다. F1 OFF는 연결 정보를 남기고 기존 시험 화면으로 돌아간다.

녹음 파일과 상태 JSON은 Drive에만 저장. 폴더·파일 공개 공유 불필요. 본문 저장 시 녹음 전체 초기화, 재녹음 시 이전 파일은 Drive 휴지통으로 이동. 음성은 저장소에 넣지 않는다.

코드 수정 후: **배포 → 배포 관리 → ✎ → 버전: 새 버전 → 배포**. 기존 주소를 유지한다. 실제 Google 권한·CORS·폰 재생은 사용자 배포 뒤 폰 2대로 확인해야 한다. 모의 테스트는 `node apps-script/Code.test.cjs`.

## F2 잠금 시험 (선택, 기본 OFF)

프로젝트 ⚙ → 스크립트 속성에 `F2_ENABLED` = `true` 추가. 최신 Code.gs를 새 버전 배포한 뒤, 그룹의 **모든 폰**에서 F1 연결 + F2 ON. 한 폰이 읽는 동안 다른 폰은 잠금 표시, 120초 내 갱신이 없으면 해제. 재녹음은 원래 입력 이름만 가능(계정 인증 아님). 서버 정책은 그룹 전체에 적용되므로 완전히 끄려면 속성도 `false`로 변경. 속성은 배포자가 관리하고 앱이 임의 변경하지 않는다.


## F3 초대·홈 화면 (선택)

폰 ③ 길게 누르기 → 설정에서 F3 ON → **홈 화면에 추가**. 자동 설치 창이 없으면 Chrome 메뉴/Safari 공유의 **홈 화면에 추가** 선택. ④ 사람 → **초대 링크 보내기** → OS 공유창에서 카톡 선택. 공유창이 없으면 복사된 링크를 붙여넣기. 연결 중인 초대에는 공유키가 포함되므로 그룹 밖으로 전달하지 않는다. 받는 사람은 링크를 연 뒤 F1을 켠다. F3 OFF는 캐시와 앱 기능을 끄며 이미 만든 홈 화면 아이콘은 폰에서 직접 삭제한다. 오프라인에서는 화면만 열리며 Drive 저장은 연결 필요.

## F5/F8 시험

최신 Code.gs를 **배포 관리 → 수정 → 새 버전**으로 배포해야 F5 배정표 API가 동작한다. 새 스크립트 속성은 불필요. 폰에서 F1 연결 + F5 ON → 이름 입력 → 1절/2절씩 배정 또는 직접 지정. 다른 폰은 배정 새로고침으로 확인. 배정만 저장하면 기존 음성은 유지된다.

F8 ON → 본문 넣기 → 제목과 붙여넣기 → 미리보기 → 기존 녹음 삭제 동의 → 저장. 본문 저장은 배정표도 지운다. 본문 넣기와 묶음 편집 메뉴는 설정에서 ADMIN_KEY를 검증한 폰에만 보인다. 서버도 같은 키를 검사한다. 실제 음성 파일은 저장소에 올리지 않는다.

## F9 묶어 읽기 시험

최신 Code.gs를 **배포 관리 → 수정 → 새 버전 → 배포**. 추가 속성 없음. 폰 ③ 길게 누르기 → 설정 → F9 ON → 묶음 편집에서 카드 둘 이상 길게 눌러 묶거나, 묶음 카드를 길게 눌러 풀기. 편집을 끈 뒤 녹음한다. F8 묶음 입력 형식은 [UI.md](../UI.md) 참고. 변경되는 범위의 녹음만 삭제 동의 후 휴지통으로 이동하므로 실제 파일로 시험하기 전 범위를 확인한다. 다른 폰은 새로고침. F2 사용 시 모든 폰에서 F2도 켠다.

## F10~F13 시험 (#39)

최신 Code.gs를 **배포 관리 → 수정 → 새 버전 → 배포**. F10 WAV와 F11 중복 방지 필드가 추가됐으며 새 속성은 없다. 폰 **③ 길게 누르기 → 설정 탭**에서 각 기능 ON. F11은 F1 연결 필요. 녹음 확인 때 연결을 끊었다 복구해서 점 표시·대기 목록·재전송을 두 폰으로 확인한다. 본문/다른 녹음 충돌은 자동 교체하지 않는다. F12는 설정에서 현재 장 WAV를 준비한 뒤 내려받기/공유, F13은 온기목장에서 문구를 복사해 카톡에 직접 붙여넣는다. #51부터 F11은 연결 시 자동 적용하며 별도 스위치는 없다. 폰 브라우저 데이터 삭제는 보관본도 지운다. 자세한 조건은 [UI.md](../UI.md), 테스트는 [tests/README.md](../tests/README.md).

## 빈 공유 본문·.txt (#42)

연결 뒤 본문이 비어 있으면 화면의 **설정 → 관리자 키 확인** 뒤 **본문 넣기**를 누르면 된다(F8 켜짐). **.txt 파일 불러오기 → 제목 확인 → 미리보기 → 기존 녹음 삭제 동의 → 저장**. UTF-8 또는 BOM 있는 UTF-16, 2MiB 이하이며 기존 최대 500절 제한을 따른다. 공유 본문은 비공개 Drive 상태 파일에 저장된다. 성경 본문/원본 txt는 공개 저장소에 올리지 않는다. F14 배경과 파일 선택은 화면 변경이므로 이 변경만을 위한 Code.gs 재배포는 필요 없다.

입력 중 보호(#43): F8/본문 편집의 저장 전 입력은 이 폰에 임시 보관·새로고침 뒤 복원한다. **Drive 저장 전** 표시를 구분하고, 복원 후 미리보기·삭제 동의·저장을 마친다. 폰 보관 실패 안내가 뜨면 새로고침 전에 복사한다. 이 수정도 서버 재배포는 필요 없다.

## F15 음악과 듣기 (#46)

F15는 기존 getAudio 조회에 브라우저 Web Audio 합성만 추가하므로 서버 재배포/속성 변경은 없다. 설정 → F15 ON → 장 이름 확인 → 곡 선택/폰 파일 선택 → 음악 음량 → 선택 절부터 이어듣기. 폰 파일/장별 곡 지정은 이 폰에만 저장하며 Drive에 올리지 않는다. 녹음 원본과 F12 음성 합본은 유지된다. 실제 음악 재료는 아직 없고 코드 시험 소리를 제공한다. 실제 두 폰/Android·iPhone에서 해독·음량·정지/다른 장 전환을 확인한다. 자세한 조건은 [UI.md](../UI.md).

## 기초 1차·본인 삭제 (#49)

③ 책·장 머리를 **한 번 누르면 책 창**, **길게 누르면 설정/사람 탭**. 신약 아래의 설정·온기목장 버튼은 제거했다. 새로고침/연결 해제는 설정 안에 있다.

새 삭제 API를 쓰려면 최신 Code.gs로 **배포 관리 → 수정 → 새 버전 → 배포**(기존 주소 유지). 이번 단계에 추가 스크립트 속성은 없다. 배포 뒤 모든 이용자 폰에서 최신 화면으로 새로고침한다. 녹음은 이 브라우저의 등록 기기 비밀값과 이름에 연결한다. 카드 두 번 탭 → 녹음, 한 번 탭 → 머리 아래로 이동, 길게 누름 → 선택 후 다른 절을 눌러 범위 확장 → 복사/삭제. 복사는 출처 포함, 삭제는 본인 파일만. 한 파일은 바로, 여러 파일은 개수 확인 후 삭제한다.

이전 기기 정보 없는 녹음은 이름만으로 삭제를 허용하지 않는다. 브라우저 데이터 삭제는 기기 증명을 잃을 수 있다. 후속 묶음은 아래 #51 참고. 서버 배포 전에는 새 화면 손동작부터 확인하고, 본인 삭제는 최신 배포 후 새로 등록한 녹음으로 확인한다.


## #51 배포·시험

1. 최신 Code.gs로 교체하고 스크립트 속성에 **ADMIN_KEY** 추가(API_KEY와 다르게). **배포 관리 → 수정 → 새 버전 → 배포**. 주소는 유지한다.
2. 폰 설정에서 관리자 키 입력·확인. 확인된 폰만 본문 넣기/편집·묶음 편집·소리 점검 목록을 쓴다. 이용자에게는 기존 공유키/초대만 전달. 키를 바꾸면 폰에서도 다시 확인.
3. 연결된 폰은 전송 실패한 녹음을 자동 보관·재전송한다. 맨 위 **보내기 대기 n개**를 누르면 목록. 새로고침/온라인 복귀·버전 충돌을 확인. 미전송 보관본은 해당 폰에만 있다.
4. 새 이름 미등록 폰은 **안내 1~4** 틀에서 이름 입력. 실제 안내 문구는 아직 자리표시.
5. **F16 ON** 뒤 실제 파일이 전부 저장된 장에서 본문 보기·절 탭 듣기·카드 복귀 확인. 타인 카드 길게 선택 → **🔧 소리 점검 → 끊김/안 들림**, 키 확인된 폰에서 목록·완료 확인.

장 재료는 [assets/chapters/catalog.json](../assets/chapters/catalog.json)에 책 제목·장 제목과 그림/음악 경로 연결. 예: `{"book":"잠언","chapter":"1장","background":"assets/bg/잠언/1.webp","music":"assets/music/잠언/1.mp3"}`. 파일이 없으면 그림/음악 없이 본문과 낭독만. 그림·음악 배포는 정적 사이트 갱신이며 Code.gs 재배포와 별개다. 현재 목록은 비어 있다. 실제 음성/본문은 추가하지 않는다.

**공유 범위 구분:** 녹음·본문 저장용 Drive 폴더는 **제한됨** 유지. Claude에게 배경 그림을 전달하는 별도 폴더는 **링크가 있는 모든 사용자(뷰어)**로 공유 가능. 전달용 폴더와 녹음 저장 폴더를 혼동하지 않는다.

## #56 설정 위치

일반 설정 맨 아래 작은 **관리자** 글자를 길게 누른다 → **관리자 키** 확인(검증된 폰이면 도구 바로 표시). F1~F16 스위치·공유 연결·본문 넣기·소리 점검 목록은 이 영역에 있다. 처음 연결할 때는 키 입력 아래 **연결 설정**에서 주소·공유키를 넣는다. 초대 링크는 이용자 폰의 연결을 자동 켠다. **일반 설정으로**는 도구만 닫고, **관리자 키 해제**는 이 폰의 키도 지운다. 서버/API 변경은 없으나, 앞선 #51의 ADMIN_KEY 설정·Code.gs 배포는 계속 필요하다.

## #59 실제 운영 순서

1. 최신 Code.gs로 교체 → **배포 관리 → 수정 → 새 버전 → 배포**. 실행 사용자 **나**, 액세스 **모든 사용자(Anyone)** 유지. Only myself면 이용자 폰이 접속하지 못한다. 기존 웹 앱 주소 유지.
2. **단톡 링크를 보내기 전에 사용자의 폰부터** 연결 → 설정 맨 아래 **관리자 길게 누르기**. 첫 폰을 한 번 등록하고 이후 자동 유지한다. 화면 비밀번호는 필요 없다. 기기 비밀값은 이 브라우저에만 보관하므로 브라우저 데이터 삭제는 피한다. 기존 ADMIN_KEY는 복구/Claude 기존 API 작업용으로 유지 가능하다.
3. Claude가 새 API로 잠언 전체 등 본문 입력. 최대 31,102절/본문 JSON 8백만 자, txt 32MiB 이하(해독 후 글자 한도 적용). 원문은 비공개 Drive에만 보관. 실제 Google Drive 읽기/쓰기 지연은 새 배포 후 사용자 폰에서 확인한다.
4. 관리자 화면 **참여 명단**에 한 줄씩 `이름, 뒷자리4자리` → **명단 등록**. 기존 명단에 추가된다. 등록 목록에서 이름별 삭제 가능. 뒷자리는 서버에 해시로만 저장하며 목록에 표시하지 않는다.
5. **초대 링크 보내기**로 단톡에 링크 하나 공유. 이용자는 **이름＋연락처 뒷자리 4자리 → 시작**. 일치하면 바로 본문, 다음 접속에는 확인 상태 기억. 홈 화면 설치 안내 한 줄도 제공한다. 명단이 등록된 뒤 구형 미가입 폰은 참여 확인 필요.
6. 관리자 화면 **테스트**는 서버 잠언 1장 1~10절의 별도 복사본. 처음부터 실제 녹음·완성 본문/F16 잠언 배경·이어듣기를 시험. **테스트 비우기**는 테스트 장 녹음만 지운다. **실제 본문으로** 돌아온다. 일반 이용자에게 테스트 책/API는 열리지 않는다.

새 속성 OWNER_DEVICE_ID/HASH·ROSTER_SALT·TEST_STATE_FILE_ID는 자동 생성. 첫 폰을 바꿔야 한다면 배포자가 OWNER_DEVICE_ID/HASH를 함께 지우고 사용자 폰을 먼저 다시 등록한다. 공유키를 아는 사람이 최초 등록을 할 수 있으므로 이 순서를 지킨다. 이미 등록된 폰은 다른 기기가 덮어쓸 수 없다. 이번 변경은 명단/등록 폰 API가 추가되어 **서버 재배포 필수**다.

## #61 화면에서 본문 넣기

머리를 길게 눌러 설정 → 관리자 모드에서 **옵션** → 페이지 화살표/좌우 쓸기로 **F8 본문 넣기** → **.txt 파일 불러오기 → 미리보기 → 기존 녹음 삭제 동의 → 저장**. 본문 저장은 기존 실제 녹음을 초기화하므로 먼저 확인한다. 이번 #61은 화면 변경만이며 Code.gs 추가 재배포는 불필요하다. 앞서 완료한 Anyone 배포는 그대로 유지한다. 사용자가 첨부한 잠언 전체 txt는 비공개 형식 검증에서 31장·915절로 확인했으며 저장소에는 포함하지 않았다. 실제 서버 입력은 관리자 폰에서 진행한다.


## #62 본문 입력 바로가기

홈 하단 **관리자 → 본문 넣기 → .txt 파일 불러오기 → 미리보기 → 기존 녹음 삭제 동의 → 저장**. 기억된 관리자 폰은 비밀번호 입력 없이 진입한다. 잠언 전체 파일은 31장·915절 형식만 검증했고 아직 서버에 입력하지 않았다. 실제 본문 저장은 기존 녹음을 초기화하므로 화면의 동의 절차를 따른다. #62는 화면 변경으로 Code.gs 재배포가 필요 없다.
