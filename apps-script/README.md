# F1 폰으로 Google 저장 연결

Android Chrome 기준. Apps Script 편집기가 좁으면 Chrome 메뉴 **데스크톱 사이트**를 켜고 가로로 돌린다. iPhone Safari도 **데스크탑 웹 사이트 요청** 사용. 편집기가 지원되지 않으면 PC가 필요할 수 있다.

1. Drive 앱에서 **+ → 폴더**로 비공개 전용 폴더 생성. 폴더 **공유 → 링크 복사**에서 `folders/` 뒤 ID만 메모. 공유 범위는 **제한됨** 유지.
2. 폰 브라우저에서 [Code.gs](https://github.com/qqcppc/relay-reading/blob/main/apps-script/Code.gs) 열기 → **Raw** → 코드 전체 선택·복사.
3. 같은 브라우저에서 [script.google.com](https://script.google.com/) → **새 프로젝트** → 기존 `Code.gs` 내용 전체를 복사한 코드로 교체 → 저장.
4. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 추가**. `DRIVE_FOLDER_ID`에 1번 ID, `API_KEY`에 길고 임의적인 그룹 공유키 입력·저장. 공유키는 공개 저장소나 단체 공개 글에 올리지 않는다. `STATE_FILE_ID`는 자동 생성: 직접 수정 금지.
5. 오른쪽 위 **배포 → 새 배포 → 유형 선택(⚙) → 웹 앱**. 실행 사용자 **나**, 액세스 **모든 사용자** → **배포**.
6. **액세스 승인**에서 본인 계정과 요청된 Drive 권한 확인·승인. 직접 만든 스크립트인 경우에만 Google의 미확인 앱 안내에서 **고급 → 본인 프로젝트로 이동**. 조직에서 익명 배포를 막으면 관리자 확인 필요.
7. 표시된 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사.
8. 낭독 화면 **⑤ ⚙ → 실험 기능 → F1 ON**. 다시 설정을 열어 **연결 주소**에 7번 주소, **공유키**에 4번 키 입력 → **연결**. 잘못된 주소·키는 연결 실패로 표시.
9. 초기 공유 본문은 비어 있다. **⑤ ⚙ → F1 → 본문 편집**에서 제목·본문 입력 후 **녹음 삭제 동의 → 저장**. 형식은 [UI.md](../UI.md) 참고. 기존 본문을 다시 저장하면 녹음이 모두 지워진다.
10. 다른 폰도 같은 주소·공유키로 연결해 녹음·조회·재생 시험. **해제**는 이 폰의 연결 정보만 지운다. F1 OFF는 연결 정보를 남기고 기존 시험 화면으로 돌아간다.

녹음 파일과 상태 JSON은 Drive에만 저장. 폴더·파일 공개 공유 불필요. 본문 저장 시 녹음 전체 초기화, 재녹음 시 이전 파일은 Drive 휴지통으로 이동. 음성은 저장소에 넣지 않는다.

코드 수정 후: **배포 → 배포 관리 → ✎ → 버전: 새 버전 → 배포**. 기존 주소를 유지한다. 실제 Google 권한·CORS·폰 재생은 사용자 배포 뒤 폰 2대로 확인해야 한다. 모의 테스트는 `node apps-script/Code.test.cjs`.

## F2 잠금 시험 (선택, 기본 OFF)

프로젝트 ⚙ → 스크립트 속성에 `F2_ENABLED` = `true` 추가. 최신 Code.gs를 새 버전 배포한 뒤, 그룹의 **모든 폰**에서 F1 연결 + F2 ON. 한 폰이 읽는 동안 다른 폰은 잠금 표시, 120초 내 갱신이 없으면 해제. 재녹음은 원래 입력 이름만 가능(계정 인증 아님). 서버 정책은 그룹 전체에 적용되므로 완전히 끄려면 속성도 `false`로 변경. 속성은 배포자가 관리하고 앱이 임의 변경하지 않는다.


## F3 초대·홈 화면 (선택)

폰 ⑤ 설정에서 F3 ON → **홈 화면에 추가**. 자동 설치 창이 없으면 Chrome 메뉴/Safari 공유의 **홈 화면에 추가** 선택. ④ 사람 → **초대 링크 보내기** → OS 공유창에서 카톡 선택. 공유창이 없으면 복사된 링크를 붙여넣기. 연결 중인 초대에는 공유키가 포함되므로 그룹 밖으로 전달하지 않는다. 받는 사람은 링크를 연 뒤 F1을 켠다. F3 OFF는 캐시와 앱 기능을 끄며 이미 만든 홈 화면 아이콘은 폰에서 직접 삭제한다. 오프라인에서는 화면만 열리며 Drive 저장은 연결 필요.

## F5/F8 시험

최신 Code.gs를 **배포 관리 → 수정 → 새 버전**으로 배포해야 F5 배정표 API가 동작한다. 새 스크립트 속성은 불필요. 폰에서 F1 연결 + F5 ON → 이름 입력 → 1절/2절씩 배정 또는 직접 지정. 다른 폰은 배정 새로고침으로 확인. 배정만 저장하면 기존 음성은 유지된다.

F8 ON → 본문 넣기 → 제목과 붙여넣기 → 미리보기 → 기존 녹음 삭제 동의 → 저장. 본문 저장은 배정표도 지운다. 그룹 공유키 사용자는 본문 변경 가능하며 F8의 관리자 표시는 별도 계정 권한이 아니다. 실제 음성 파일은 저장소에 올리지 않는다.

## F9 묶어 읽기 시험

최신 Code.gs를 **배포 관리 → 수정 → 새 버전 → 배포**. 추가 속성 없음. 폰 ⑤ 설정 → F9 ON → 묶음 편집에서 카드 둘 이상 길게 눌러 묶거나, 묶음 카드를 길게 눌러 풀기. 편집을 끈 뒤 녹음한다. F8 묶음 입력 형식은 [UI.md](../UI.md) 참고. 변경되는 범위의 녹음만 삭제 동의 후 휴지통으로 이동하므로 실제 파일로 시험하기 전 범위를 확인한다. 다른 폰은 새로고침. F2 사용 시 모든 폰에서 F2도 켠다.
