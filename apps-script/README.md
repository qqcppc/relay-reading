# Google Apps Script 배포

1. Google Drive에 **전용 비공개 폴더** 생성. 다른 파일이 든 폴더/공개 공유 폴더 사용 금지.
2. [Apps Script](https://script.google.com/) 새 프로젝트 → `Code.gs` 내용 붙여넣기.
3. 프로젝트 설정 → 스크립트 속성에 `DRIVE_FOLDER_ID`(폴더 URL의 ID), `API_TOKEN`(충분히 긴 임의 공유 암호) 설정. 암호는 저장소에 넣지 않는다.
4. **배포 → 새 배포 → 웹 앱**. 실행 사용자 **나**, 접근 권한 **모든 사용자**(조직 정책에 따라 불가할 수 있음). Drive 권한 승인 후 `/exec` 주소 복사. 공유 암호를 아는 사람은 모든 녹음을 조회/교체하고 본문을 수정할 수 있음.
5. 화면 담당에게 웹 앱 주소와 [API.md](API.md) 전달. 암호는 별도로 안전하게 전달하고 화면에서 입력받기. 녹음/상태 파일은 Drive에만 저장. 공개 Drive 공유 불필요.
6. 코드 변경 후 **배포 관리 → 수정 → 새 버전**으로 갱신.

## 배포 후 확인

- `getText`로 빈 본문 확인 → `saveText`로 시험 본문 저장.
- 실제 브라우저에서 webm/ogg 녹음 업로드 → 목록의 이름·절·시각 확인 → `getAudio` 응답을 Blob으로 바꿔 재생.
- 같은 절 재업로드 후 목록 한 항목 유지, 이전 Drive 파일 휴지통 이동 확인.
- 다른 폰에서 조회/재생하고 잘못된 암호가 거부되는지 확인. 브라우저의 리다이렉트/CORS도 여기서 확인.
- 본문 변경 시 **모든 기존 녹음 삭제**. 필요하면 먼저 Drive 백업. 기존과 동일한 본문 저장은 녹음 유지.

음성은 최대 10MiB/절. 공유 암호는 개인별 인증이 아니며 GET 쿼리/브라우저 기록에 남을 수 있으므로 조회도 POST 권장. Apps Script 실행 시간·Drive 할당량 적용. 서버가 중간 종료되면 참조되지 않는 파일이 남을 수 있어 전용 폴더 점검 필요. 이 구현은 단일 본문용이며 사용자별 쓰기 제한은 없음.

로컬 검증: 저장소 루트에서 `node --test apps-script/Code.test.cjs`. Google 서비스 모의 테스트이며 실제 배포/권한/브라우저 재생을 대신하지 않음. 별도 의존성 설치 불필요(Node.js 18 이상).
