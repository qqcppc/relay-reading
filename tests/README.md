# 테스트 실행

저장소 루트에서 Node.js 24 이상 사용. 화면은 정적 파일이라 앱 빌드/실행 의존성은 없다. 테스트 도구만 설치한다.

```sh
npm ci
npx playwright install chromium
npm test
npm run test:browser
```

시스템 Chromium을 쓸 경우:

```sh
BROWSER_EXECUTABLE=/usr/bin/chromium npm run test:browser
```

- `npm test`: 10개 파일의 단위/API 검사(38개 사례). Apps Script·Drive는 메모리 모의 서비스, WAV도 합성 PCM 바이트만 사용한다.
- `features-smoke.cjs`: F1 연결/두 폰 F2/이름별 교체/F3 실제 SW·오프라인·공유·OFF 복귀.
- `settings-smoke.cjs`: 테마·글꼴·기억·저장 차단·모바일 시트.
- `f4-f8-smoke.cjs`: F4+F5 자동 시작/배정 동기화/F7 실제 해독/F8 입력·동의·복원.
- `f9-smoke.cjs`: 묶음 녹음/첫 절 키/범위 잠금/격자색/배정/편집·동의.
- `long-1-smoke.cjs`: F10 실제 Web Audio 무음 자르기·비교, F11 IndexedDB 재시작·두 탭·응답 유실·본문 충돌·저장 실패, F12 묶음 WAV·명시적 파일 공유, F13 장 완성·목표·복사.
- `bg-seed-smoke.cjs`: F14 A~J·스크롤·동작 줄이기·다크·그림 오프라인 캐시, 빈 공유 본문의 F8 직접 진입, UTF-8/UTF-16 파일·오류·늦은 읽기·저장 동의. A~J와 다크 확인 화면은 `tests/results/background-*.png`에 생성한다. 실제 성경 본문은 테스트에 넣지 않는다.
- `drafts-smoke.cjs`: 입력/파일 초안의 새로고침·스위치 재시작 복원, 저장 성공 정리, 서버 목록 갱신 중 입력 보존, 그룹 범위·삭제·저장 실패 이탈 경고.
- `picker-progress-smoke.cjs`: 가짜 예약 없음/실제 F2 잠금·사람 색·해제, 책·장 실제 절 비율/묶음/대기·연출 제외/완료 표시.
- `f15-smoke.cjs`: 실제 Web Audio 그래프를 OfflineAudioContext로 렌더해 음악 덕킹/회복과 피크 확인. 절별 음량·여백·반복, 장 경계 음악 전환/음악 없음, 재생 중 음량 변경, 폰 파일 기억/잘못된 파일/삭제, 정적 곡 캐시, 읽기 취소/마이크 시작/버전 충돌 검증. 음악·목소리는 합성 PCM 메모리 바이트만 사용한다.
- `basics-smoke.cjs`: 세로→가로 쓸기 차단, 머리 한 번/길게, 한 번 이동/두 번 녹음/길게 선택·범위 복사·폰 뒤로가기, 본인/타인·묶음 삭제와 확인 횟수, 전체 듣기 가운데 따라가기, 마이크/카톡 안내. 서버 테스트는 기기 비밀값·이름·갱신 충돌·잠금·기존 미등록 녹음을 따로 확인한다.
- `screen-smoke.cjs`: 현재 겹친 책·장 머리/20칸 격자 쓸기/구약·신약 4열/머리 길게 눌러 사람·설정 시트, 전체 기능 ON·OFF·교차 조합, F10~F15 스위치 재시작·복귀. `ui-smoke.cjs`는 이 검사의 호환 진입점이다.

## 390×800 화면 비교

`npm run test:visual`은 `tests/baselines/`의 6장과 비교한다. viewport 390×800, deviceScaleFactor 1, 밝은 테마, ko-KR. 애니메이션을 끄고 화면 버전 번호만 `#V`로 고정한다. 픽셀 색 차이 threshold 0.1, 전체 차이 0.3% 초과 시 실패한다. 실패 화면/차이는 git에서 제외한 `tests/results/`에 저장한다.

현재 기준: Linux(Debian 13), Chromium 154.0.8037.57, 환경 기본 글꼴(OpenAI Sans 및 한국어 대체 글꼴). 브라우저/OS/글꼴이 달라 생긴 차이는 실제 화면 변경과 구분해 검토한다. 기준을 바꿀 때는 아래 명령 후 PNG 6장을 직접 확인하고 커밋한다. 기능 조합은 같은 읽기 기준 이미지에 계속 비교한다.

```sh
UPDATE_SCREENSHOTS=1 BROWSER_EXECUTABLE=/usr/bin/chromium npm run test:visual
```

음성은 가상 마이크·메모리 Blob·테스트용 IndexedDB만 사용한다. WAV 다운로드는 Blob URL을 메모리에서 해독하며 파일로 저장하지 않는다. 실제 녹음 파일은 저장소에 넣지 않는다. 실제 Google 배포 권한/CORS, 카톡 붙여넣기·파일 공유, iPhone/Android의 마이크·해독·설치·저장 용량은 사용자 배포 후 폰에서 별도 확인한다.


#51: `tests/basics2-smoke.cjs`는 실제 서버 권한 검증·키 해제/재시작, 이름 없는 첫 안내, 소리 점검 비공개 목록, F11 OFF 상태의 기본 보관/시작 재전송, 완성/미완성 장·묶음 강조·탭/카드 전환·장 그림/음악을 검증한다. 본문은 예시 문자열, 소리는 메모리에서 만든 PCM만 사용한다. 기존 편집 테스트만 별도의 `helpers/admin.cjs`로 검증용 키를 넣으며 HTTP 라우트는 호출자의 필드를 그대로 서버에 전달한다.

#56: `settings2-smoke.cjs`는 공용 크기 버튼/실제 크기 미리보기, 기존 값 이관·기억, 책/절 카드 1~5열·한계, 버전 이름·본문 유지, 무채색 다크·이름, 관리자 짧게/길게 누름·키 오류/검증/해제·일반 설정 복귀·최초 연결·초대 자동 연결을 검증한다. 기존 관리자 기능 테스트는 명시적인 테스트 키와 관리자 모드로 실행한다. 보내기 대기 목록은 별도 창으로 검증한다.

#59: `live.test.cjs`는 31,102절·별도 본문 파일/작은 상태·첫 관리자 등록 탈취 거부·명단 해시·기기 세션/이름 강제·명단 변경 무효화·실패 제한·테스트 공간/초기화 격리를 검증한다. `live-smoke.cjs`는 31,102절에서 장 20번 렌더(4초 이내), 66권·준비 중, 비밀번호 없는 첫 폰/재시작, 관리자 기본 실험, 별도 10절 테스트/F16 잠언 배경/이어듣기/비우기, 초대 명단 확인/일반 모드/복원을 검증한다. 본문은 예시 문자열만, 소리는 메모리 PCM만 사용한다. Drive 실제 지연·Google 배포 권한은 새 배포 후 별도 확인한다.

#61: `frame-smoke.cjs`(settings2-smoke에서 실행)는 320×568/390×800/430×700/844×390의 검색·설정 넘침, 버전 팝업·순환 버튼·같은 줄 크기 선택, 고정 목록 칸 수/절 크기 한계, 본문만 스크롤, 사람/옵션 페이지, 관리자 권한·스위치 새로고침 뒤 탭/페이지 복원을 검증한다. 기존 기능 테스트는 `helpers/frame.cjs`로 실제 탭/페이지를 선택한 뒤 조작한다. 권한을 우회하거나 hidden을 임의 해제하지 않는다. 기준 이미지 6장도 새 구조로 갱신했다.


#62: 브라우저 실행기는 16종이다. `bottom-smoke.cjs`는 하단 5버튼·관리자 본문 직접 진입, B1 크기/간격, B2/B3 최대 50개·현재 장 묶음·상하/좌우 이동, 진행 색, 작은 세로/가로 화면 넘침, 닫힌 창 뒤 홈 버튼 접근을 검증한다. `feedback-smoke.cjs`는 가상 마이크와 지연 응답으로 더블탭 반응, 저장/삭제 처리 중→실제 완료, 중복 방지, 실패 초안 유지, 임시 녹음 삭제, 전송 대기 구분을 확인한다. `live-smoke.cjs`는 일반 모드에서 관리자 재진입 후 본문 넣기도 확인한다. 기준 화면 6장을 새 하단 구조로 갱신했다.


#63: 브라우저17종, 단위/API13파일(기존45+규칙4사례). `recording-flow-smoke.cjs`는 새 브라우저의 로컬 파일 입력·복원과 빈 서버 첫 관리자 등록→txt입력→본문 표시를 실제 UI로 확인한다. 탭/길게/탭+길게·정확히 누른 다음 절 자동 저장·재녹음/취소·뒤로가기·4버튼·점3개 메뉴·하트/장 잠금·장 완성→대표기도→다음 장, 시트/패널·새로고침·책명 레이어를 검증한다. `feedback-smoke.cjs`는 지연 업로드 도중 그만하기의 다음 녹음 방지도 확인한다. `chapter-flow.test.cjs`는 익명 메타데이터·타인 음성 거부·3개 한도/토글/마감, 서버 시간6+6시간·수동 양도·선착순 중복 거부, 본문 초기화/권한/버전, 여러 폰 동일 회원·기기 위장을 검증한다. 기준6장을 갱신했다. 물리 볼륨키·실제 모바일 OS/Drive 응답은 이 테스트로 보장하지 않는다.

#64: `solo.test.cjs`는 관리자 키·등록 폰 없이 기본 단독 편집, 이전 owner/명단 상태가 남은 경우, 명시적 그룹 모드의 기존 검증을 확인한다. `solo-settings-smoke.cjs`는 frame-smoke 진입점에서 실행되며 키 입력 없이 실제 파일 저장, 단일 책 패널·위치별 길게 누름·네이티브 하단5탭, 교회/목장 자리·알림 지원 표시, 순환 버튼 최초 제목/값 기억/초기화·줄바꿈, 두 미리보기의3요소·독립 크기·4줄 본문, 320/390/844/1024 화면을 검증한다. 기존 권한 UI 검사는 단독 도구와 키 없는 실제 입력으로 대체했으며 그룹 권한 API 검사는 유지한다. 브라우저17종, 단위/API14파일(기존49+단독2사례), 기준 화면6장.

#65: solo-settings 검사는 미리보기/블록 높이 고정, 최대 확대 정지, 창세기→창 자동 축약·정식 유지·개인 로마 표기를 확인한다. basics2 검사는 테마 변경 시 backgroundDark/기본 그림의 실제 이미지 선택 전환을 확인한다. 다크 자산 검사는 기존 이미지 바이트를 쓰는 테스트 경로이며 사용자01_2 원본을 대체하지 않는다.

#66: f15-smoke는 선택한 파일이 빈 chapterMusic보다 우선하는지, 실제 F12 버튼의 Blob을 해독해48kHz/2채널·유효 피크·음성 시작 전 음악 신호·음악 포함 상태를 확인한다. 기존 정규화·덕킹·음악 루프·지연 취소·파일 기억/삭제 검사를 유지한다. 모두 합성 WAV/PCM이며 실제 사용자 음악이나 목소리 파일은 저장하지 않는다.
