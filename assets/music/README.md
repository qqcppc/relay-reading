# 배경 음악 재료

사용자가 만든/제공한 사용 가능한 배경 음악만 이 폴더에 둔다. 낭독 음성이나 성경 본문은 넣지 않는다. 현재 실제 곡은 없으며 앱의 「잔잔한 시험 소리」는 코드로 합성한다.

곡을 추가할 때 가볍게 압축한 mp3/ogg(권장) 파일과 catalog.json을 함께 수정한다:

```json
{"tracks":[{"id":"calm","title":"잔잔한 곡","file":"calm.mp3"}]}
```

위 예시는 형식 설명이며 실제 파일을 제공할 때만 목록에 넣는다. 파일명은 같은 폴더 안의 이름(하위 경로/외부 URL 없음), id는 영문·숫자·하이픈·밑줄 1~64자. 최대 30곡. 앱 버전(index ?v·sw VERSION·f3-app)을 함께 갱신한다. F3는 재생한 정적 음악을 캐시해 이후 오프라인에서 쓸 수 있다. 폰에서 고른 개인 음악은 이 폴더에 업로드하지 않고 그 폰 IndexedDB에만 보관한다.
